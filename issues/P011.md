# P011: Transaction Postgres bị aborted sau unique violation (LRN-002)

id: P011
status: mitigated
tier: A · area: database-concurrency · date: 2026-07-13 · confidence: medium
resolution type: code-fix, process-rule

## Problem

Bắt unique violation rồi đọc lại trong cùng transaction PostgreSQL tường minh thì transaction đã aborted, mất đường phục hồi.

## Root cause

PostgreSQL đánh dấu transaction aborted sau câu lệnh lỗi.

## Resolution

Insert/catch/read nằm ngoài transaction tường minh (safety.service). Vẫn thiếu regression test; sau đó d506ca2 áp dụng cùng nguyên tắc cho short-video.
