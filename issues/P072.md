# P072: Windows: Nx build lỗi 1314 + runner timeout (exit 124)

id: P072
status: mitigated
tier: B · area: windows-toolchain · date: 2026-08-20 · confidence: low
resolution type: process-rule

## Problem

Trên Windows: quality gate/nx build/test bị runner timeout không log (exit 124), Nx build báo os error 1314, next build ngoài Nx thiếu NEXT_PUBLIC_*, next-env.d.ts bị sinh đổi, lệnh cài package chạy nhầm thư mục cha.

## Root cause

Giới hạn watchdog tool, dev server giữ .next, build direct thiếu env, workdir lệch; không phải lỗi logic.

## Resolution

Chạy tách target, tắt dev server rồi build lại, cấp env NEXT_PUBLIC_* local, hoàn tác next-env.d.ts, gỡ package cài nhầm ở thư mục cha.
