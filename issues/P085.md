# P085: Guest reload mất device token → Matching 401

id: P085
status: open
tier: A · area: frontend-ux · date: 2026-10-09 · confidence: high
resolution type: none-yet

## Problem

Guest reload trang rồi vào Matching: POST /matching/tickets trả 401; GET /support/tickets/me cũng có thể 401. SPA navigation không reload thì 201.

## Root cause

guestDeviceToken chỉ lưu trong memory (token-store.ts), mất sau reload; matching.controller yêu cầu header X-Guest-Device-Token.

## Resolution

Chỉ chẩn đoán: cần lưu/reissue guest token khi restore session và guard query support trước khi có phiên; chưa thấy commit sửa.
