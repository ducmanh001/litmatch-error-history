# P022: CVE ở runtime image mà pre-push local bỏ sót

id: P022
status: fixed
tier: A · area: ci-cd · date: 2026-07-22 · confidence: medium
resolution type: ci-config, code-fix, dependency-bump

## Problem

CVE ở runtime image (Web/Edge, Go cũ, toolchain thừa) bị GitHub phát hiện trong khi pre-push local vẫn xanh vì bỏ sót image.

## Root cause

Pre-push local không build/scan đủ bốn runtime image; Edge build bằng Go cũ, Web image giữ package manager.

## Resolution

Pre-push gọi pnpm ci:preflight (build+scan đủ 4 image); Web xoá package manager; Edge build Caddy bằng Go đã vá, chạy nobody; pin bản vá trong pnpm-workspace.yaml; pnpm audit high PASS.
