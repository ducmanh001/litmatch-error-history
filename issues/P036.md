# P036: Windows: hook/runner không chạy được pnpm (.cmd: 127 / EINVAL)

id: P036
status: fixed
tier: A · area: windows-toolchain · date: 2026-08-14 · confidence: high
resolution type: code-fix

## Problem

git push bị hook pre-push chặn: 'pnpm: command not found' (code 127), sau đó spawn EINVAL khi chạy pnpm.cmd.

## Root cause

Git Bash/Husky nhận PATH cũ thiếu %APPDATA%/npm; run-stage.mjs spawn trực tiếp pnpm.cmd không qua shell trên Windows.

## Resolution

Hook pre-commit/pre-push tự thêm %APPDATA%/npm và Program Files/nodejs vào PATH; scripts/ci/run-stage.mjs dùng shell cho .cmd/.bat (test 5/5). Commit 3f231ca, eba5763.
