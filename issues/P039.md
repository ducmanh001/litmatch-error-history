## Problem

Local gate trên Windows đỏ giả: security-tools 16 test, markdown-links, pre-tool-guard, module-boundaries 14 test fail do path/platform.

## Root cause

Test giả định path POSIX/$HOME, URL.pathname thành /C:/..., snapshot boundary dùng dấu \ thay vì /.

## Resolution

Sửa test dùng path separator/homedir đa nền tảng, chuẩn hóa POSIX trong module-boundaries.spec.ts; dry-run không đòi Linux/Docker. Trước đó push --no-verify có kiểm soát.
