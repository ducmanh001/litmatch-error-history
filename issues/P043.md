## Problem

Nx cache đang bật cho test tích hợp có state (core-api, signaling Redis) và E2E, có thể trả kết quả cũ dù DB/Redis đổi.

## Root cause

Nx hash không bao gồm trạng thái DB/Redis runtime; target e2e/test stateful vẫn cache mặc định.

## Resolution

Tắt cache cho core-api/signaling-gateway test, toàn bộ E2E và target web atomized; thêm LOCAL_CI_STRICT_CLEAN và Docker Buildx GHA cache. Commit 79bea23.
