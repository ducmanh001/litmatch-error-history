## Problem

E2E local fail lẫn lộn: server core-api/signaling cũ còn sống, Core E2E reset DB khi Web E2E đang đăng nhập; web E2E thiếu baseUrl alias và lệnh PORT không chạy trên Windows.

## Root cause

Teardown dùng process.kill(-pid) kiểu Unix; --parallel=2 chung DB; tsconfig.base mất baseUrl; PORT=... không tương thích Windows.

## Resolution

isolated-node-server.ts dùng taskkill /T /F; E2E --parallel=1; khôi phục baseUrl trong tsconfig.base.json; sửa playwright.config.mts. Signaling 2/2, core 12/12, web 1/1 PASS.
