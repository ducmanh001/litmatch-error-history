# P107: File CRLF trong working tree: sửa bằng script phải giữ EOL

id: P107
status: fixed
tier: B · area: ai-agent-process · date: 2026-10-09 · confidence: medium
resolution type: process-rule

## Problem

Một số file (deploy/production/.env.example) là CRLF trong working tree; script sửa dễ làm đổi EOL và sinh diff nhiễu.

## Root cause

Repo trộn LF/CRLF trên Windows (.gitattributes chỉ áp một phần).

## Resolution

Script sửa file giữ nguyên EOL của từng file.
