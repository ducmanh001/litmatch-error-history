# P046: Guest bấm Matching → 401 vì thiếu X-Guest-Device-Token

id: P046
status: fixed
tier: A · area: matching · date: 2026-08-14 · confidence: high
resolution type: code-fix, test-added

## Problem

Guest bấm Matching trên web luôn lỗi 401 MATCHING_GUEST_DEVICE_TOKEN_REQUIRED dù guest login thành công.

## Root cause

Backend bắt header X-Guest-Device-Token nhưng frontend chỉ lưu accessToken/csrfToken, không lưu và không gửi guestDeviceToken.

## Resolution

Lưu guestDeviceToken trong memory ở token-store (libs/api-client) và client.ts tự gắn header cho Matching; thêm test token-store/client. Hard reload chưa giữ token (ghi nhận là hạn chế).
