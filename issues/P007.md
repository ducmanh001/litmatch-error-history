# P007: CI hosted lệch CI local (runner sạch)

id: P007
status: fixed
tier: A · area: ci-cd · date: 2026-07-13 · confidence: high
resolution type: ci-config, dependency-bump, test-added

## Problem

CI hosted lệch local: @eslint/js không resolve trên runner sạch, Next build thiếu 3 NEXT_PUBLIC_*, gitleaks chặn secret giả lịch sử, Docker job bị skipped, actionlint bắt ShellCheck mà local bỏ sót, action dùng Node 20.

## Root cause

@eslint/js chỉ có qua dependency bắc cầu; local có cache/env nên pass; local gate không cài ShellCheck.

## Resolution

Thêm pnpm ci:preflight và hook pre-push chạy Node 22 container sạch; .gitleaks-baseline theo fingerprint; local tự cài ShellCheck pin SHA-256; nâng pnpm/action-setup và upload-artifact lên bản Node 24; workflow-policy.mjs có test.
