# P097: Sửa script qua shell lồng quote làm hỏng regex; Workflow scriptPath bị từ chối

id: P097
status: fixed
tier: B · area: ai-agent-process · date: 2026-10-09 · confidence: medium
resolution type: code-fix, process-rule

## Problem

Sửa script build qua shell lồng quote làm hỏng regex; swap-limits cắt luôn hàm renderFindings; Workflow scriptPath bị từ chối; sơ đồ cắt nhãn >3 dòng (64/1007 bước).

## Root cause

Dùng sed/node -e với quoting lồng nhau; scriptPath phải là file do tool trả về; renderer giới hạn 3 dòng.

## Resolution

Dùng Write/Edit thay shell, chèn lại renderFindings, truyền args.tasks cho Workflow, nâng giới hạn nhãn lên 7 dòng.
