# P037: Windows/Docker: CRLF + symlink thành file thường làm format/agent:check đỏ

id: P037
status: fixed
tier: A · area: windows-toolchain · date: 2026-08-14 · confidence: high
resolution type: code-fix, env-config

## Problem

Trên Windows pnpm format:check báo ~1.428 file và 9 alias symlink (CLAUDE.md, SKILL.md) bị checkout thành file thường, trong khi CI Linux chỉ báo 2 file.

## Root cause

Checkout Windows lẫn CRLF/LF, chưa có rule eol; symlink bị materialize thành file làm Prettier đòi newline và agent:check fail.

## Resolution

Thêm .gitattributes ép LF, .prettierignore loại alias symlink, bật core.symlinks; adapter-parity chỉ chấp nhận file materialized khi nội dung khớp target trong index. Commit f717299, 86e1a45.
