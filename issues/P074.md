# P074: Core API production crash lúc boot (media storage dev / thiếu biến R2)

id: P074
status: in-progress
tier: A · area: deploy-config · date: 2026-08-21 · confidence: high
resolution type: env-config, redeploy

## Problem

Core API production crash khi khởi động nên bản mới không chạy, route profile 404; sau khi đổi sang r2 lại crash tiếp vì thiếu biến R2.

## Root cause

Env production để MEDIA_STORAGE_PROVIDER=dev (DevImageStorageProvider bị cấm ở prod); sau đó thiếu/để placeholder các biến MEDIA_R2_* và MEDIA_PUBLIC_BASE_URL nên R2ImageStorageProvider ném lỗi.

## Resolution

Đổi MEDIA_STORAGE_PROVIDER=r2 (user đã làm) và hướng dẫn cấp đủ 5 biến R2 (ACCOUNT_ID, BUCKET, ACCESS_KEY_ID, SECRET_ACCESS_KEY, PUBLIC_BASE_URL) rồi redeploy. Chưa thấy bằng chứng deploy cuối thành công.
