# P061: Lỗi TS ở tsconfig.spec không làm build fail

id: P061
status: mitigated
tier: B · area: observability · date: 2026-08-14 · confidence: high
resolution type: env-config, none-yet

## Problem

Lỗi/cảnh báo TypeScript ở tsconfig.spec.json của signaling-gateway vẫn cho build qua; user muốn tắt tạm cảnh báo.

## Root cause

Target build chỉ chạy webpack-cli với tsconfig.app.json, không có target typecheck; VS Code có thể dùng TypeScript khác bản workspace 5.9.3.

## Resolution

Tạm thời ép VS Code dùng TS workspace qua .vscode/settings.json (typescript.tsdk); ignoreDeprecations 6.0 bị gỡ vì không hợp TS 5.9. Đề xuất thêm target typecheck cho build phụ thuộc, chưa làm.
