## Problem

Tiến trình pnpm ci:preflight chạy song song bị treo và làm mất các thay đổi chưa commit (fix button + payload) trong working tree.

## Root cause

Preflight chạy nền làm worktree quay về sạch giữa lúc agent làm việc; chạy gate song song gây race cache.

## Resolution

Dừng đúng hai PID preflight, khôi phục lại 8 file bằng patch, chỉ chạy test targeted sau đó.
