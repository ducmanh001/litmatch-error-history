# P060: tsconfig baseUrl deprecated → mất alias lúc runtime

id: P060
status: fixed
tier: A · area: windows-toolchain · date: 2026-08-14 · confidence: medium
resolution type: code-fix

## Problem

VS Code đỏ vì cảnh báo baseUrl/moduleResolution 'node' deprecated; sau khi bỏ baseUrl, openapi:check không resolve @litmatch/logger.

## Root cause

tsconfig.base.json dùng baseUrl deprecated; tsconfig-paths/register cũ không rebase paths từ file extends nên runtime mất alias sau khi bỏ baseUrl.

## Resolution

Xoá baseUrl khỏi tsconfig.base.json, moduleResolution thành node10 ở core-api/signaling-gateway; thêm scripts/register-tsconfig-paths.cjs và sửa apps/core-api/project.json, openapi-check.mjs. OpenAPI check PASS.
