# P029: Nhiều đường bypass gate CI (hook local / GitHub / hosted lệch nhau)

id: P029
status: fixed
tier: B · area: ci-cd · date: 2026-07-30 · confidence: high
resolution type: ci-config, test-added

## Problem

Hook local, GitHub Actions và hosted release dùng gate khác nhau, còn đường bypass; release không bắt buộc ci.yml push run thành công trên main.

## Root cause

Contract CI không thống nhất, gate chạy được ở chế độ không fail-closed.

## Resolution

Hợp nhất 1 contract fail-closed, bỏ bypass, release yêu cầu run ci.yml thành công đúng commit, gate check-only deterministic (NX_TUI=false, frozen lockfile), cô lập Nx state; thêm test workflow-policy.

## Evidence

- commit ab57f9b — "remove CI/hosted bypass paths and require an exact successful `ci.yml` push run on `main`"
- pr #50
