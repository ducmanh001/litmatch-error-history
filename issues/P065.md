# P065: Production chạy bản cũ: route profile 404, thông báo Facebook cũ

id: P065
status: open
tier: A · area: deploy-config · date: 2026-08-19 · confidence: high
resolution type: env-config, none-yet, redeploy

## Problem

Bấm Theo dõi/Nhắn tin ở profile báo lỗi đỏ 'Cannot POST /api/v1/profiles/.../follow'; sau đó GET /profiles/:id/actions trả 404 COMMON_ROUTE_NOT_FOUND và UI khóa hai nút.

## Root cause

Không phải lỗi frontend/contract: source và OpenAPI đã có route. Core API runtime/prod đang chạy bản cũ hoặc chưa load ProfileSocialController (deploy chưa cập nhật); local DB còn thiếu 3 migration profile.

## Resolution

Local: chạy 3 migration profile, bật lại core-api rồi xác nhận route follow/conversation đã load. Prod: khuyến nghị deploy lại core-api đúng source hiện tại, giữ NEXT_PUBLIC_API_URL. FE không thêm fallback giả.
